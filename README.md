# Ashes of Midgard

A single-player browser ARPG in the style of Ragnarok Online, with a dark Norse story. The World Tree has burned; hunt the three Shardbearers and face the Ashen King.

Play: https://cesardellantonio.github.io/ashes-of-midgard/

No build step or server needed: it is plain HTML and JavaScript with three.js from a CDN. Progress saves in your browser.
